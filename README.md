# OpenGL_project

Overview

This project is a 3D interactive graphics application developed using modern OpenGL (programmable pipeline). It demonstrates real-time rendering techniques, camera control, lighting models, texturing, and shadow mapping within a dynamic 3D environment.

The application allows the user to explore a fully rendered scene with multiple objects, realistic lighting, and advanced visual effects, showcasing both graphics programming knowledge and practical implementation skills.

Features

Modern OpenGL rendering pipeline (shaders-based)

Interactive camera (keyboard + mouse control)

Multiple lighting types:

-Directional light

-Point light

-Flashlight (spotlight attached to camera)

Real-time shadows (shadow mapping)

Texture mapping and material system

Skybox for environment rendering

Fog effect for depth realism

Multiple rendering modes:

Solid

Wireframe

Polygonal

Smooth shading

Toggleable lighting and visual effects

Controls
Camera Movement

W / A / S / D — Move camera

Mouse — Look around

Scroll — Zoom

Rendering Modes

1 — Directional light

2 — Point light

3 — Flashlight

4 — Solid view

5 — Wireframe view

6 — Polygonal view

7 — Smooth view

N — Enable / Disable lighting

Technologies Used

C++

OpenGL

GLFW

GLAD / GLEW (depending on your setup)

GLM (mathematics library)

Assimp (for model loading)

stb_image (texture loading)

Learning Objectives

This project was created to deepen understanding of:

-Real-time rendering pipelines

-GPU programming with shaders

-3D transformations and camera systems

-Lighting and shading models

-Graphics optimization techniques
